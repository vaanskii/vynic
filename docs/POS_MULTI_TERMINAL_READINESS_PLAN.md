## Required milestones

1. Correct the Windows launcher while retaining provenance/owner/link checks.
   Configure stable station IDs and revisions. Separate physical destination
   from command language, paper/raster width, cutter and sound. TCP and Windows
   RAW are generic transports; RAW requires a compatible installed queue and
   frozen Device/queue/driver/port. It does not establish arbitrary USB/serial or
   driver-rendered compatibility. Driver-rendered documents need their own
   renderer. Accepted bytes never establish paper.
2. Freeze bytes, Venue, route/revision, capabilities and business-effect identity
   before dispatch. Flush send-start before bytes; crash/lost replies stay
   uncertain. No automatic retries or uncertain-job takeover. Explicit stable
   line destinations route kitchen/bar/additional work. Production copies use
   Run/Cancel with background actor/request audit. Owner receipt/paper/no-byte
   retry policy still needs a persisted decision.
3. Keep unknown/unsupported/disabled sound silent. Enable only explicitly
   compatible commands, without model-name inference or probes. Settle primary
   print/cut first; durably reserve each signal attempt and record its separate
   result. Never replay sound after uncertainty/crash, alter primary results or
   cause print/cut/reprint because a signal failed.
4. Select one explicit LAN Edge installation/epoch as Venue shared-write
   authority. Cloud outages remain supported. Unreachable LAN authority fails
   shared writes closed; cached reads show freshness. No automatic failover or
   Cloud-to-LAN calls. Controlled handover must stop/fence the old offline host;
   a new Cloud epoch alone cannot fence it.
5. Integrate every writer: Order/Table, closure/Sale/money, transfer/cancel,
   reservations/packages, Close Day, audit, Cloud work, printing, numbering,
   startup/repair/restore/replacement and updates. Stable requests, read
   dependencies and revisions prevent stale edits. Atomically commit changes,
   exact durable results and frozen effects. Store-only CAS and Orders/Tables
   shadow are foundations, not multi-terminal proof. Documented Menu/Inventory
   ownership remains authoritative.
6. Prove three synthetic authenticated terminals before ten: simultaneous table
   opens, stale edits, transfer/payment/cancel/Close Day races, lost replies and
   stable retries, revocation, crash/replay, LAN partitions, Cloud outage,
   restart, old-host return and controlled handover. Prove one effect and one
   printer owner. Then measure ten-terminal contention and bounded latency/load.
7. Fix reachable advisories and verify locked installs, migrations and runtime
   tests. Record dormant reachability and unresolved Prisma CLI compatibility.
   Qualify signed/versioned source, binaries and metadata, exact Windows target,
   reader floor, compatible rollback, full restore and replacement-PC rehearsal.
   Print v2/Edge schema changes need compatible readers before publication. An
   old reader refusing new data is containment, not a successful rollback.
8. Preserve separate promised-surface gates: MGR-02/MGR-05 and delivery/freshness
   for Manager writes; WEB-01/03/04 and provider sandbox evidence for paid
   reservations/payments. Fix these before enabling the affected capabilities.

## External evidence and decisions

- Exact Windows target, model label, cable endpoints, queue/driver/port, paper,
  command language and cutter. A model qualifies a device without restricting
  the architecture to that vendor.
- Owner receipt/paper/no-byte policy and explicitly compatible sound enablement.
- Exact approval before physical jobs, drivers, live mutations or destructive
  tests. Existing VM work stays within its separately authorized scope.
- Task-local acquisition for absent tooling. No global installation, new trust/
  credentials, push, deployment or merge is implied.

Each milestone requires proportional tests, independent review and a
source-identified proof. Commit only fully accepted owned work; never include
unrelated WIP or mark a missing necessary check DONE.
