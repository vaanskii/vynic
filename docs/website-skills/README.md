# Vynic Website Skills

This pack defines how to design and build a modern public website for the Vynic restaurant POS product.

Use these files together:

- `VYNIC_WEBSITE_MASTER_SKILL.md` - product positioning, audience, constraints, and success criteria.
- `VYNIC_WEBSITE_VISUAL_DIRECTION.md` - visual language, layout, color, type, imagery, and UI treatment.
- `VYNIC_WEBSITE_SCREENS_AND_CONTENT.md` - pages, sections, screenshots, copy direction, and product flows.
- `VYNIC_WEBSITE_SCROLL_ANIMATION_SKILL.md` - scroll animations, interaction rules, and reduced-motion fallbacks.
- `VYNIC_WEBSITE_BUILD_PROMPT.md` - ready prompt for the agent that will create the actual site.

The website should feel like a serious restaurant operations product, not a generic SaaS landing page. It should show real Vynic screens, explain the restaurant workflows, and make the local Georgian operational fit obvious.
