# Vynic launch film: Georgian voice-over v2 (proposal, awaiting voice approval)

**Status:** voice review only. The film has **not** been retimed or re-rendered. The v1 voice (`VOICEOVER_GE.md`, `assets/audio/vo/`) is untouched until a voice is approved.

## What changed from v1

- **Silent opening:** there is no voice for the first **3.4 s**. The mark draws, "Vynic" resolves and the music breathes. The first line starts only as the camera leaves the identity for the restaurant (the camera move moves from 4.4 s to about 3.2 s).
- **No technical English is spoken:**
  - Gone: SaaS, Custom, POS, Cloud, Dashboard and Inventory.
  - Only "Vynic" (read "ვაინიკ") is spoken in English. The on-screen tags can keep SAAS, CUSTOM and POS.
- **Short phrases, one clip each:** 16 clips instead of 11 long sentences. Each phrase is its own file, so it can be re-timed, re-generated or replaced individually.
- **The lines follow the picture instead of listing features:**
  - "მაგიდა იხსნება" lands on the table tap.
  - "შეკვეთა იქმნება" lands as the items go in.
  - "მომსახურება იწყება" lands on confirm.
- **More silence:**
  - Speech is about **38 s of a ~63.5 s film (60%)**. Counting the short pauses inside passages, it is about 65%.
  - The website scene opens, the fold, and the lockup each get music-only space.

### Language notes for your review

- **Informal "შენ":** lines 12 and 13 use informal "you" ("შეგიძლია", "შენს ბრენდზე"), following your draft. Say if you prefer the formal "თქვენ" ("შეგიძლიათ", "თქვენს ბრენდზე").
- **"მუშაობას" instead of "ოპერაციას":** line 05 uses "work", because "ოპერაცია" reads as technical or medical when spoken.
- **"მომწოდებლებთან დავალიანება" (what is owed to suppliers):** used instead of "მომწოდებლის ვალდებულებები". It matches the Manager screen "გადახდები და დავალიანება".
- **Line 13 "გქონდეს" ("have"):** chosen instead of "შექმნა" ("create") so it does not suggest the customer builds or deploys the custom site themselves. Custom sites are individual builds, not an automatic product.
- **Lockup echo:** voice_14/15 ("ერთი რესტორანი. ერთი დაკავშირებული სისტემა.") are followed by the on-screen tagline "რესტორანი. ერთ სისტემაში.", which says nearly the same thing. If that feels repetitive, final-line option 2 ("სერვისიდან ონლაინამდე — ერთი Vynic.") avoids it. This is not changed yet.

### Claims check

- **No absolute or ranking claims:** no realtime, offline, "zero loss", "best" or "#1" claim, and no named architecture.
- **Line 06:** says only that information does not stay in one place. It makes no speed claim.
- **Line 10:** "when you need it" describes looking things up on the phone. The picture shows pull-to-refresh, not live streaming.
- **Line 11:** true. The ready-made and custom sites both run on the same Vynic backend.

## Voice review: renders/voice-review/

Every voice reads the **same test passage** (voice_01 to voice_05 with the designed pauses):

> რესტორანში ყველაფერი მოძრაობაშია. — მაგიდა იხსნება. — შეკვეთა იქმნება. — მომსახურება იწყება. — Vynic რესტორნის ყოველდღიურ მუშაობას ერთ სივრცეში აერთიანებს.

| File | Voice | Direction | Speaking rate | Test passage |
|---|---|---|---|---|
| `voice-a.wav` | Giorgi (Microsoft neural) | Engine defaults; no processing | 5.75 syllables/s | 12.9 s |
| `voice-b.wav` | Giorgi | 6% slower, pitch −3 Hz, warm EQ (a little body at 160 Hz, softer 3.3 kHz edge, gentle 2:1 levelling) | 5.40 syllables/s | 13.5 s |
| `voice-c.wav` | Giorgi | 10% slower, pitch −8 Hz, the same warm EQ | 5.18 syllables/s | 14.0 s |

**Also in the folder:**
- `voice-a-script.wav`, `voice-b-script.wav` and `voice-c-script.wav`: the **whole v2 script** in each voice, placed at the timestamps above over 63.5 s, voice only. Use these to judge the pacing and silences.
- `lines/a|b|c/voice_01.wav … voice_16.wav`: every line in every voice as separate clips, so you can pick the best take per line, e.g. B for most lines and A for a line that sounds more natural at the default rate.
- `stats.json`: every clip's length and each voice's gain.

**Levels:** all files are level-matched to about −18.5 LUFS, so the comparison is fair (loudness does not favour one take).

**Why the three are one speaker:**
- The only male Georgian neural voice reachable here is **Giorgi**. The same service's other Georgian voice, Eka, is female.
- **Higgsfield:** 0 credits.
- **Other vendors:** no ElevenLabs, Azure or Gemini keys.
- **Meta MMS:** Meta's open speech model has **no Georgian** voice.
- **Community models:** the Georgian models on Hugging Face are low-use, unreviewed voice-cloning fine-tunes, and I did not run them.

So A, B and C compare **direction** (pace, pitch, colour), not different speakers. A real speaker change needs one of these: a recorded Georgian voice actor, credits on Higgsfield, or an ElevenLabs or Azure key.

**Licence:** Microsoft Edge TTS is **not licensed for commercial release**. Whichever voice is picked is a timing placeholder until a licensed voice or a human recording replaces it.

**Why the v1 voice sounded robotic** (fixed in all three v2 voices):
- **Long sentences:** v1 packed a feature list into long sentences with a comma chain, so the engine read it at one flat pitch.
- **Clipped pauses:** v1 cut every internal pause to 0.45 s, which made the rhythm mechanical.

v2 has short sentences, each generated separately so each ends with its own natural cadence. Pauses are placed between clips by design, and pauses inside a clip are left exactly as spoken.

## After a voice is approved (not done yet)

1. Copy the chosen `lines/<v>/voice_XX.wav` clips (mixing takes is fine) into `assets/audio/vo/` and replace the v1 `<audio class="vo">` clips in `index.html` with the 16 v2 clips at the starts above.
2. Retime the picture to the speech:
   - move the opening camera move to about 3.2 s;
   - slow the POS beats slightly so tap, items and confirm land under lines 02–04;
   - extend Manager by about 3 s;
   - end about 63.5 s.
3. Re-time the music's section changes to the new scene times, then re-run the voice carve and `npm run render`.

Regenerate this review with:

```bash
EDGE_TTS=/path/to/edge-tts npm run voice:review
```

The script reads `audio/vo-v2-lines.json` and `audio/voice-review.mjs`, and needs Docker or `FFMPEG=/path/to/ffmpeg`.
